### 📊 Architettura del Database
Il progetto implementa i seguenti pattern relazionali:

*   **Many-to-Many (N:M):** Gestione di `Books` ↔ `Authors`, implementata tramite tabelle pivot ottimizzate.
*   **Many-to-Many (N:M):** Gestione di `Books` ↔ `Categories`, implementata tramite tabelle pivot ottimizzate.

💻 Tech Stack
Il progetto è stato sviluppato utilizzando le seguenti tecnologie:

Backend: Laravel.
Database: MySQL.
